# Gourav Sharma — Personal Portfolio

A clean, modern, and responsive personal developer portfolio designed to showcase my projects, skills, and experience as a Full-Stack Web Developer. 

🔗 **Live Site:** [https://gouravsharma26.github.io/Portfolioyo/](https://gouravsharma26.github.io/Portfolioyo/)

## Features
- **Modern UI/UX**: Premium dark mode aesthetic with custom styling and animations.
- **Dynamic Interactions**: Features a custom magnetic cursor and a dynamic typewriter effect in the hero section.
- **Vanilla Tech Stack**: Built entirely from scratch using pure HTML5, CSS3, and Vanilla JavaScript—no heavy frameworks or build steps required.
- **Fully Responsive**: Optimized for seamless viewing across mobile, tablet, and desktop screens.
- **Easter Eggs**: Includes an interactive command palette and a secret terminal with a playable Snake game!

## Project Architecture
- `assets/` - Contains all static images and documents (e.g., resume).
- `css/` - Core stylesheets (`style.css`).
- `js/` - JavaScript logic including dynamic project rendering (`projects-data.js`) and UI interactions (`site-common.js`).
- `index.html`, `projects.html`, `project.html` - The core markup files.

## Local Development
Since this is a vanilla static site, getting it running locally is incredibly simple:
1. Clone this repository.
2. Open `index.html` in your web browser. 

*(Note: For the absolute best development experience, it is recommended to serve the folder using a lightweight local server like VS Code's **Live Server** extension).*
